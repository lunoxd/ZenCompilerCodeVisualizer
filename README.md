# Code Visualizer

> Visualize your code. Understand how it works.

Code Visualizer is an open-source tool for visualizing code execution in a simple and interactive way.

Instead of only seeing the final output, Code Visualizer helps you see what happens while your program runs — including execution flow, variables, functions, and program state.
